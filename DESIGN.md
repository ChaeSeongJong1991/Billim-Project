# Design System — Billim (빌림)

> 건물/호실 임대 관리 플랫폼 | 임대인 & 임차인 인터페이스

---

## Product Context

- **What this is:** 임대인(Landlord)이 건물·호실·계약·수납·유지보수를 통합 관리하는 B2B 웹 앱
- **Who it's for:** 다수 건물을 운영하는 개인 임대인 및 소규모 임대 사업자
- **Space/industry:** PropTech (부동산 관리 SaaS), 한국 임대 시장
- **Project type:** 데이터 중심 관리자 대시보드 + 임차인 셀프서비스 포털
- **Peers:** 렌트잇, 집주인닷컴, Buildium, AppFolio

---

## Aesthetic Direction

- **Direction:** Industrial/Utilitarian with Warmth
- **Decoration level:** Intentional — 기능 우선, 구조가 장식을 겸함
- **Mood:** 신뢰감 있고 조용하게 유능한 느낌. 과하지 않고 데이터가 주인공이 되는 인터페이스. 임대인이 매일 쓰는 도구이므로 피로감이 없어야 한다.
- **Anti-patterns avoided:** 보라/바이올렛 그라디언트, 동그란 아이콘 격자, 과한 애니메이션, 제네릭 스톡 이미지 히어로

---

## Spacing

- **Base unit:** 4px
- **Density:** Comfortable (임대인은 데이터 밀도 필요, 임차인은 여유 있게)

| Token | Value  | Usage                              |
|-------|--------|------------------------------------|
| 2xs   | 2px    | 아이콘 내부 여백                   |
| xs    | 4px    | 뱃지 패딩, 인라인 간격             |
| sm    | 8px    | 버튼 세로 패딩, 라벨 간격          |
| md    | 16px   | 카드 패딩, 폼 필드 간격            |
| lg    | 24px   | 섹션 간격, 카드 하단 여백          |
| xl    | 32px   | 페이지 헤딩 여백                   |
| 2xl   | 48px   | 주요 섹션 구분                     |
| 3xl   | 64px   | 히어로 패딩                        |

---

## Layout

- **Approach:** Grid-disciplined (앱 영역) + Creative-editorial (랜딩 페이지)
- **Grid:** 12컬럼 | 768px: 8컬럼 | 640px 이하: 4컬럼
- **Max content width:** 1280px (xl breakpoint)
- **Sidebar width:** 240px (collapsed: 64px)

**Border Radius:**

| Token    | Value  | Usage                        |
|----------|--------|------------------------------|
| `sm`     | 4px    | 입력 필드, 뱃지              |
| `md`     | 8px    | 버튼, 카드                   |
| `lg`     | 12px   | 모달, 드롭다운 패널           |
| `xl`     | 16px   | 대형 카드, 시트               |
| `full`   | 9999px | 칩, 아바타, 토글              |

---

## Motion

- **Approach:** Minimal-functional
- **Easing:** enter(ease-out) exit(ease-in) move(ease-in-out)
- **Duration:**

| Token    | Duration    | Usage                             |
|----------|-------------|-----------------------------------|
| micro    | 50–100ms    | 뱃지 색상 전환, 체크박스           |
| short    | 150–250ms   | 버튼 hover, 드롭다운 열기         |
| medium   | 250–400ms   | 모달 등장, 사이드바 토글          |
| long     | 400–700ms   | 페이지 전환                       |
