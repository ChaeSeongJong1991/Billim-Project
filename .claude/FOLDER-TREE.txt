구조 특징
==========

✓ Domain-Driven: 도메인별 폴더 구조 (tenant, admin, vendor)
✓ Feature-Based: 기능별로 page.tsx와 components 분리
✓ Reusable: 공통 컴포넌트 중앙 집중식 관리
✓ Scalable: 각 도메인 독립적 성장 가능
✓ Type-Safe: TypeScript 기반 Props 정의
✓ Testable: 작은 단위 컴포넌트로 테스트 용이
✓ Accessible: a11y 고려한 컴포넌트 설계


파일 명명 규칙
==============

Pages:        page.tsx (Next.js 컨벤션)
Layouts:      layout.tsx
Components:   PascalCase.tsx (e.g., WorkOrderCard.tsx)
Hooks:        useCamelCase.ts (e.g., useWorkOrders.ts)
Utils:        camelCase.ts (e.g., validation.ts)
Types:        types.ts 또는 FileName.types.ts
