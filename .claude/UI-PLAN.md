## 📱 페이지 구조

### 1. 임차인(Tenant) UI

#### 1.1 대시보드 (`/tenant/workorder`)
**목적**: 내 민원 상태 한눈에 보기

```
┌─ Header ────────────────────────────────┐
│  🏠 건물명 / 호실명              🔔 알림 │
├─────────────────────────────────────────┤
│                                         │
│  ┌─ 빠른 통계 ────────────────────────┐ │
│  │ 진행중: 2  │  완료대기: 1        │ │
│  │ 완료: 12   │  작년대비: +3       │ │
│  └─────────────────────────────────────┘ │
│                                         │
│  ┌─ 최근 민원 (3개) ──────────────────┐ │
│  │ [카드] 누수 - 진행중 (2일)        │ │
│  │ [카드] 가전 - 접수됨             │ │
│  │ [카드] 배관 - 완료 ✓            │ │
│  └─────────────────────────────────────┘ │
│                                         │
│         [+ 새 민원 접수 하기]          │
└─────────────────────────────────────────┘
```

**컴포넌트**:
- `TenantHeader` - 건물/호실 정보 + 알림 버튼
- `QuickStats` - 4칸 통계 (진행중/완료대기/완료/작년대비)
- `RecentWorkOrderCard` - 민원 카드 (3개까지)
- `PrimaryButton` - 새 민원 접수

**상태**:
- 접수 초기: 통계만 표시
- 1개 이상: 최근 민원 표시

#### 1.2 민원 접수 페이지 (`/tenant/workorder/create`)
**목적**: 사진과 함께 수리 요청 제출

```
┌─ Header ────────────────────────────────┐
│  ← 취소                   새 민원 접수   │
├─────────────────────────────────────────┤
│                                         │
│  제목 *                                 │
│  [Input] 예) 화장실 누수                 │
│                                         │
│  카테고리 *                             │
│  ◯ 누수     ◯ 가전     ◯ 전기           │
│  ◯ 배관     ◯ 기타                     │
│                                         │
│  설명 *                                 │
│  [TextArea] 상세 설명...                 │
│                                         │
│  우선순위 (선택)                       │
│  ◯ 낮음     ◯ 중간     ◯ 높음           │
│                                         │
│  사진 첨부 * (최대 5장)                 │
│  ┌──────────────────────────────────┐ │
│  │ + 사진 추가 (드래그 & 드롭)      │ │
│  │                                  │ │
│  │ [사진1] [사진2] [사진3]           │ │
│  └──────────────────────────────────┘ │
│                                         │
│                [제출]  [임시 저장]      │
└─────────────────────────────────────────┘
```

**컴포넌트**:
- `FormHeader` - 뒤로가기 + 제목
- `TextInput` - 제목 (required)
- `CategorySelect` - 라디오 그룹 (required)
- `TextArea` - 상세 설명 (required)
- `PrioritySelect` - 라디오 그룹 (optional)
- `ImageUpload` - 드래그 드롭 + 파일 선택
- `ImagePreview` - 업로드된 이미지 미리보기 (삭제 가능)
- `FormActions` - 제출 + 임시 저장 버튼

**상태**:
- 입력 중: 빨간 별(*) 표시, 필수 필드 강조
- 이미지 드래그: 드롭 영역 하이라이트 (파란색 border)
- 제출 중: 버튼 disabled + 로딩 스피너
- 성공: 토스트 + 상세 페이지로 리다이렉트

- `DetailHeader` - 뒤로가기 + 제목

- `BasicInfoCard` - 우선순위, 접수일, 카테고리, 상태
- `DescriptionCard` - 민원 설명
- `ImageGallery` - 이미지 갤러리 (클릭 시 확대)
- `ContractorCard` - 배정 업체 정보
  - 업체명, 연락처, 이메일
  - 평점 + 완료 건수
  - 복사 버튼
- `TimelineLog` - 진행 상황 로그
  - 날짜/시간, 아이콘, 상태 변화, 담당자
- `ActionButtons` - 추가 질문, 취소 요청

**상태**:
- 접수: 진행률 0%, 업체 미배정
- 진행중: 진행률 50%, 업체 정보 표시
- 완료: 진행률 100%, 완료 배지
- 취소: 회색 처리, "취소됨" 배지

#### 2.3 민원 관리 - 상세 뷰 (`/admin/maintenance/workorders/[id]`)

## 🎯 인터랙션 & 상태

### 폼 검증
1. **입력 중**: 실시간 검증 (onBlur)
2. **에러**: 필드 아래 빨간 메시지

### 알림
- **성공**: 초록색 토스트 (3초 자동 닫힘)
- **에러**: 빨간색 토스트 (자동 닫히지 않음)
- **정보**: 파란색 토스트

### 로딩
- **버튼**: disabled + 스피너
- **페이지**: 스켈레톤 스크린
- **목록**: 무한 스크롤 (다음 페이지 자동 로드)

### 드래그 & 드롭
- **보드**: 카드 간 드래그로 상태 변경
- **파일**: 이미지 드롭 또는 클릭 업로드
